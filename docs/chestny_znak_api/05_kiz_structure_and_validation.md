## 1. Анатомия Кода GS1 DataMatrix

Код маркировки «Честный Знак» представляет собой двумерный матричный штрихкод DataMatrix (GS1 ECC 200), состоящий из 4 групп идентификаторов применения (Application Identifiers — AI):

```
(01) 04670033010052 (21) sY2n!t <GS> (91) ffd0 <GS> (92) 4v8K1...crypto...
|_________________| |_______|       |_____|       |____________________|
     1. GTIN          2. SN         3. Key ID         4. Криптохвост
    (14 цифр)       (12 симв)       (4 симв)            (44 симв)
```

### Составные части:
1. **AI `01` — GTIN (Global Trade Item Number)**: 14-значный код товара.
2. **AI `21` — Серийный номер (SN)**: Уникальный серийный номер единицы продукции (6-13 символов).
   *Комбинация GTIN + Serial Number формирует **SGTIN (Код Идентификации)**.*
3. **Разделитель групп `<GS>`**: ASCII символ 29 (`\x1d` или `\u001d`), разделяющий поля переменной длины.
4. **AI `91` — Идентификатор ключа проверки**: 4 символа (выдается ЦРПТ).
5. **AI `92` — Код проверки (Криптохвост)**: Электронная подпись кода, обеспечивающая защиту от подделки.

## 2. Особенности считывания 2D-сканером

> [!IMPORTANT]
> 2D-сканеры штрихкодов в режиме эмуляции клавиатуры (HID POS) по умолчанию могут отсекать или преобразовывать символ `<GS>` (ASCII 29) в пробел или спец-символ.
> В сканере КИЗ сервиса [`frontend/index.html`](file:///D:/PyCharm_Projects/WB%20FBS/frontend/index.html) и в модуле валидации предусмотрена нормализация:
> - Распознавание символов `\u001d`, `~`, `^]`.
> - Извлечение чистого SGTIN для передачи в WB API (`PUT /meta/sgtin`).

## 3. Онлайн-Валидация КИЗ через True API

### Эндпоинт: `POST /api/v3/true-api/cises/info`
Позволяет проверить статус кода перед привязкой к заказу и отправкой покупателю.

#### Тело запроса:
```json
[
  "0104670033010052215sY2n!t"
]
```

#### Пример ответа ГИС МТ:
```json
[
  {
    "cis": "0104670033010052215sY2n!t",
    "gtin": "04670033010052",
    "status": "INTRODUCED",
    "ownerInn": "7701234567",
    "ownerName": "ООО ТЕКСТИЛЬ ТРЕЙД",
    "productGroup": "lp",
    "producedDate": "2026-08-01T00:00:00Z"
  }
]
```

### Критерии успешной валидации для отгрузки:
- `status`: **`INTRODUCED`** (Находится в обороте).
- `ownerInn`: Совпадает с ИНН текущего продавца (`seller.cz_inn`).
- `productGroup`: Соответствует товарной группе номенклатуры.
